# 심야 편의점 큐 시트

`pnpm cues`로 만든 파일이다. 직접 고치지 말고 `src/game/script.ts`(큐 위치)와 `src/game/media.ts`(목록)를 고친다.

## 컷씬 그림 파일

`src/assets/cuts/`에 id 이름으로 넣으면 바로 붙는다. `<id>.gif`(한 장, 움직이는 그림 가능) 또는 `<id>.1.webp` + `<id>.2.webp`(두 장 → 넘김). 쓰이는 곳의 (N줄)은 컷씬이 떠 있는 대사 수.
